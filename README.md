# Tip & Bill Splitter

An interactive, mobile-friendly tip and bill calculator built to practice JavaScript DOM manipulation, form validation, and Bootstrap 5.

## Live Demo
[View Live App](https://github.io)

## Built With
* HTML5
* Bootstrap 5
* Vanilla JavaScript (ES6+)

## Features
* Calculates tip per person and total per person dynamically
* Input validation with Bootstrap error alerts
* Responsive card layout for mobile and desktop
